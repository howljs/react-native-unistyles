# macOS support

`apps/example-macos` is a standalone validation host for Unistyles on the latest
stable React Native macOS release used by this branch.

## Version alignment

The host intentionally follows the peer versions declared by
`react-native-macos@0.81.9` and the tooling from the matching React Native
Community template:

| Package | Version |
|---|---|
| `react-native-macos` | `0.81.9` |
| `react-native` | `0.81.6` |
| `react` | `19.1.4` |
| `@react-native-community/cli` | `20.0.0` |
| `@react-native-community/cli-platform-ios` | `20.0.0` |
| `@react-native/babel-preset` | `0.81.6` |
| `@react-native/metro-config` | `0.81.6` |
| `@react-native/typescript-config` | `0.81.6` |

Do not upgrade `react-native` independently. Select a stable
`react-native-macos` release first, then use its exact React Native peer version
and the corresponding Community template tooling.

The native project was generated by the generator bundled with
`react-native-macos@0.81.9`. The host also pins Reanimated `4.1.7` and Worklets
`0.7.4`; that pair supports React Native 0.81 and includes the macOS display-link
guards needed by a native build.

## Validation

From the repository root:

```sh
bun install --frozen-lockfile
cd apps/example-macos/macos && pod install
xcodebuild \
  -workspace examplemacos.xcworkspace \
  -scheme examplemacos-macOS \
  -configuration Debug \
  -derivedDataPath build/DerivedData \
  CODE_SIGNING_ALLOWED=NO \
  build
```

The host currently exercises static and variant styles, manual theme changes,
responsive breakpoints, and Reanimated styles. Platform-specific capability
details will be kept here as the macOS implementation expands.
